# To-Do List

A small, dependency-free to-do list app in a single HTML file.

## Features

- Add, complete, edit (double-click) and delete tasks
- Filter by All / Active / Done, and clear finished tasks
- Tasks are saved in the browser's `localStorage`
- Light and dark mode follow your system setting

## Run it

Open `index.html` in any browser — no build step or server needed.

Or serve the folder locally:

```bash
npx serve todo-app
```
